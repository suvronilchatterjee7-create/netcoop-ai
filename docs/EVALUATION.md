## Definitions

- **Label:** the scenario family of the ground-truth root cause, from the generator's own parameters. For `interop_failure` runs it is the underlying network state, so they count by what is really wrong.
- **Correct:** the claimed fault maps to that family **and** the claimed root is a true location; for normal runs, `no_fault_detected`. Any other diagnosis or no-fault claim is **wrong**. `insufficient_evidence` is an **abstention** (never correct, never wrong).
- **Macro-F1:** per-label precision is computed over claims, and recall over all runs of that label (abstentions count as misses); the mean is unweighted.
- **Localisation:** *root localisation* is the share of right-type claims whose root is a true location. *Affected-set* precision and recall compare `affected_devices` with the generator's ground truth (|affected ∩ true| / |affected| and / |true|). The report deliberately lists every place where users feel the fault (probe vantage points, service names), while the generator lists only the faulty elements, so the affected-set precision understates localisation by design.
- **Abstention precision / recall:** the 'best guess' is the correlator's top candidate (or 'normal' when there is none). An abstention is justified if that guess was wrong. Recall is the share of wrong best guesses that were withheld.
- **Calibration:** every ranked candidate's calibrated confidence against whether it is the true fault at a true location.
